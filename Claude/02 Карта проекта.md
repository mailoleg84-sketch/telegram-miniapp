# Карта проекта

> Навигация по коду. Связано с [[00 Индекс проекта]] · [[03 Технический аудит]].
> Дата составления: 2026-06-08.

## Общая структура

```
Tutor/
├── main.py                     # точка входа: aiogram + aiohttp вместе
├── config.py                   # конфигурация, env, возрастные профили
├── database.py                 # PostgreSQL/asyncpg: схема + все запросы
├── handlers/                   # хендлеры бота (лаунчер Mini App)
├── webapp/                     # ядро приложения (API + ИИ + фронтенд)
│   ├── server.py               # aiohttp API, все эндпоинты
│   ├── openai_service.py       # OpenAI: чат, TTS, Whisper, Realtime, картинки
│   ├── lesson_engine.py        # машина состояний урока (чистая)
│   ├── auth.py                 # проверка подписи Telegram initData
│   ├── vocabulary_visualizer.py# визуальные карточки слов
│   ├── free_images.py          # бесплатные картинки (Pixabay)
│   └── static/                 # фронтенд (SPA)
├── data/                       # банки слов
├── tools/                      # утилиты и скрипты
├── tests/                      # тесты
├── Dockerfile, render.yaml     # деплой
└── .env / .env.example         # секреты (.env НЕ читать)
```

## Где находится фронтенд

`webapp/static/` — `app.js` (4806 стр., вся логика SPA), `index.html`, `styles.css`, `design.css`. Vanilla JS/CSS, без сборщика. Прототип нового дизайна — `prototype.html`.

## Где находится бэкенд

`webapp/server.py` (aiohttp, 3819 стр.) — основной API. `main.py` — точка входа. `handlers/` — бот. ИИ-логика — `webapp/openai_service.py`.

## Где база данных

`database.py` — единственный модуль доступа к данным. Схема создаётся в `init_db()` (idempotent `CREATE TABLE / ALTER ... IF NOT EXISTS`), **отдельных миграций нет**. СУБД — PostgreSQL (Neon) через `asyncpg`, пул соединений. Подключение — через `DATABASE_URL`.

## Где конфиги

`config.py` (читает env), `.env` (секреты — **не читать**), `.env.example` (шаблон), `render.yaml`, `Dockerfile`, `.dockerignore`, `requirements.txt`.

## Где стили и интерфейс

`webapp/static/styles.css` (базовые стили), `design.css` (дизайн-система, возрастная адаптация темы), `index.html` (каркас). Логика UI — в `app.js`.

## Где логика обучения

- Машина урока: `webapp/lesson_engine.py`.
- Банки слов: `data/words.py`, `data/single_words_5000.py`.
- Эндпоинты словаря/тренировок/квиза/игры: `webapp/server.py` (`api_vocab_*`, `api_choice_*`, `api_input_*`, `api_word_hunt_*`).
- Визуальные карточки: `webapp/vocabulary_visualizer.py`.

## Где голосовой модуль

- `webapp/openai_service.py` — Realtime WebRTC, Whisper (распознавание), TTS (озвучка), safety.
- `webapp/server.py` — эндпоинты `api_realtime_*`, `api_audio_*`, голосовые ходы.
- `config.py` — `REALTIME_AGE_PROFILES` (возрастные параметры голоса).
- Документация: `VOICE_TUTOR_ARCHITECTURE.md`, `VOICE_QA_CHECKLIST.md`.

## Где генерация картинок

- `webapp/vocabulary_visualizer.py` — сборка карточки (эмодзи / визуальный тип).
- `webapp/server.py` — SVG-генераторы (`_word_image_svg`, `_vocabulary_visual_svg`), эндпоинты картинок, кэш.
- `webapp/openai_service.py` — `generate_vocabulary_image` (gpt-image-1) + vision-ревью.
- `webapp/free_images.py` — Pixabay-фото.
- Кэш — на диске (`webapp/static/generated/`, эфемерный на Render).

## Рискованные места (менять осторожно)

- `webapp/auth.py` — авторизация. Ошибка = дыра в доступе.
- `webapp/lesson_engine.py` — чистая машина состояний, покрыта тестами.
- Safety-слой контента для детей (в `openai_service.py`, `database.py:BLOCKED_SEED_WORDS`).
- `database.py` — схема/миграции в `init_db` (удаление колонок опасно для данных Neon).
- `data/single_words_5000.py` — баланс по возрастам, проверяется тестом.
- Контракт payload между `server.py` и `app.js`.
