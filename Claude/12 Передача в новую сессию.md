## Что это за проект
Telegram Mini App «AI English Tutor Kids» — репетитор английского для детей **5–18 лет**.

**Стек:** Python · `aiogram` 3 (бот-лаунчер, webhook) · `aiohttp` (API) · `asyncpg` + PostgreSQL (Neon) · OpenAI (chat gpt-4o-mini, TTS gpt-4o-mini-tts, Whisper, Realtime gpt-realtime-2, gpt-image-1). Фронт — vanilla JS SPA.

**Ключевые файлы:**
- `main.py` — точка входа (бот + aiohttp в одном процессе; webhook на Render, polling локально). Graceful shutdown по SIGTERM.
- `webapp/server.py` — aiohttp-приложение + маршруты; `create_app()`, `run_webapp()`.
- Роуты: `webapp/routes_admin.py`, `webapp/routes_training.py`, `webapp/routes_chat_voice.py`.
- `database.py` — asyncpg, `init_db()` (создание таблиц + `_seed_words`), пул `max_size=5`, `command_timeout=60`.
- `webapp/openai_service.py` — вся работа с OpenAI (chat_reply, realtime, TTS, safety-guard).
- `webapp/vocabulary_visualizer.py` — `WORD_EMOJI`, `build_vocabulary_visual`, `is_sensitive_word`.
- `data/words.py` → `LEARNING_WORDS` (из `data/single_words_5000.py` = 5000 + 6 `_TOPIC_PLAN_WORDS` = **5006**; сидится в `words`).
- Фронт: `webapp/static/app.js` (~5000 строк, vanilla JS, глобальные render*-функции, общий `state`), `styles.css`, `design.css`.
