### 2026-06-08 — Возрастная группа выводится из возраста ребёнка

**Контекст:** При создании профиля ребёнок указывал и точный возраст, и отдельно выбирал возрастную группу — избыточно и можно ошибиться.
**Решение:** Убрать ручной выбор группы; вычислять её из возраста на бэкенде (`_age_group_from_age`).
**Почему так:** Меньше шагов в онбординге, единый источник истины (возраст), исключены противоречия возраст↔группа.
**Риски:** Существующие профили — их `age_group` уже в БД, не затронуты. API стал принимать `age_group` опционально (обратная совместимость).
**Что проверить позже:** Корректность возрастной адаптации (слова, голос, тема) для новых профилей всех возрастов.

### 2026-06-08 — Webhook-секрет обязателен в проде

**Контекст:** Раньше webhook принимался без секрета — любой мог слать поддельные апдейты боту.
**Решение:** В webhook-режиме бот не стартует без `TELEGRAM_WEBHOOK_SECRET` (fail-fast).
**Почему так:** Закрывает реальную уязвимость подделки апдейтов.
**Риски:** Требует задать переменную в Render env (сделано). Локальный polling не затронут.
**Что проверить позже:** При смене окружения/деплое не забыть про переменную.

### 2026-06-08 — Документация проекта в Obsidian (папка `Claude`)

**Контекст:** Нужна устойчивая база для работы через связку Obsidian + Claude Code + Git.
**Решение:** Нумерованный набор `.md` в `Claude/` (индекс, правила, карта, аудит, задачи, журналы, промты, идеи) + `CLAUDE.md` в корне.
**Почему так:** Прозрачный рабочий процесс «план → подтверждение → правка → проверка → отчёт».
**Риски:** Дублирование с ранними доками (`Технический аудит.md`, `План задач для Codex.md`) — оставлены, консолидация по подтверждению.
**Что проверить позже:** Поддерживать журналы в актуальном состоянии после каждой задачи.
