## 2026-06-08 — Первые задачи: кэш index.html, gzip статики, лог JSON

Выполнены первые 3 задачи из [[05 Первые задачи]] — маленькие безопасные улучшения стабильности и скорости. Бизнес-логика не менялась.

**Задача 1 — кэш `index.html` в памяти.** `index_handler` больше не читает файл с диска на каждый запрос; обработанный HTML кэшируется в памяти (для dev — сброс через `INDEX_HTML_NO_CACHE`). Файл: `webapp/server.py`.

**Задача 2 — gzip + Cache-Control для статики.** В `hardening_middleware` для путей `/static/` добавлены `Cache-Control: public, max-age=86400` и gzip для текстовых ассетов (`.js/.css/.svg/.json/.map`). Список middleware не трогался (тест на точную строку). Версионирование `?v=APP_VERSION` в `index.html` уже было. Файл: `webapp/server.py`.

**Задача 3 — лог битого JSON.** `_safe_json` теперь пишет `log.warning` с путём запроса при ошибке парсинга; поток управления и возврат не изменены. Файл: `webapp/server.py`.

**Проверки:** `py_compile webapp/server.py` — OK; тесты — **59/59 passed**.
