## Назначение проекта

**AI English Tutor Kids** — Telegram Mini App, персональный AI-репетитор английского языка для детей и подростков **5–18 лет**.

- Покупатель — родитель: видит прогресс ребёнка, результаты тестов и список выученных слов.
- Бот делает одно — даёт кнопку «📱 Открыть приложение». Всё обучение — внутри Mini App.
- Возможности: возрастной тест уровня, урок дня, изучение слов с карточками и квизом, тренировки, игра «Словесная охота», голосовой репетитор (Realtime WebRTC), словарь с повторением, достижения, родительский отчёт.

## Как работать с проектом

1. **Obsidian** хранит документацию, планы, аудит, задачи и решения (эта папка `Claude`).
2. **Claude Code** анализирует проект и вносит изменения **только после подтверждения** (см. [[01 Правила работы]] и `CLAUDE.md` в корне).
3. **Git** используется для контроля версий и отката.
4. После каждого изменения — запись в [[06 Журнал изменений]]; важные технические решения — в [[07 Журнал решений]].

## Схема работы

```
Obsidian (документация, планы, аудит)
        │
        ▼
Claude Code (анализ → план → подтверждение → правка → проверка → отчёт)
        │
        ▼
Git (версии, откат) → push в main → авто-деплой на Render
```
