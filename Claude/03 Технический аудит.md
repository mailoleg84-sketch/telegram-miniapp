## Общая оценка

Зрелый MVP с понятной доменной логикой, но с признаками быстрого роста. Готовность к развитию — **~7/10**. Сильные стороны: грамотная авторизация (HMAC initData + fallback), параметризованный SQL, чистая машина урока, есть тесты на ключевую логику. Слабые: два файла-гиганта концентрируют почти всё, нет сервисного слоя, состояние в памяти и эфемерный диск → допущение «один инстанс».

## Архитектурные риски

- **God-objects:** `webapp/server.py` (3819 стр.) и `webapp/static/app.js` (4806 стр.) смешивают почти всю логику.
- **Нет сервисного слоя:** обработчики `server.py` напрямую дёргают `database.*` и содержат бизнес-цепочки из 8–10 `await`.
- **Протечка слоёв:** `database.py` импортирует визуализатор из `webapp/`.
- **Жёсткая связанность фронт↔бэк:** `app.js` завязан на форму ответов по строковым ключам, нет версионирования API.
- **Дублирование:** выборка тренировочного слова, подсчёт результатов, prompt-context, нормализация возраста (частично закрыто ✅).
- **Контент в коде:** `LEVEL_TESTS` и `TOPIC_PLANS` перемешаны с логикой.

## Производительность

- 🟠 **N+1 запросы** в квизах/тренировках → +0.5–1 с на сессию.
- 🟠 **Эфемерный диск** для кэшей картинок/аудио → повторная оплата OpenAI после деплоя.
- 🟡 **Блокирующий I/O** в event loop: `index.html` читается с диска на каждый запрос; сид 5000 слов; `glob`+`stat` в обработчиках.
- 🟡 **`ORDER BY RANDOM()`** в ~12 местах — full scan при росте банка.
- 🟡 **`app.js` 196 КБ без gzip/минификации** — медленно на мобильном.
- ✅ **Индексы БД** на горячих таблицах — добавлены (Этап 1).

## Безопасность

- ✅ **Webhook-секрет** обязателен (Этап 1).
- ✅ **Суточный лимит Realtime** — добавлен (Этап 1).
- ✅ **CSP + валидация типа аудио** — добавлены (Этап 1).
- 🟡 **Safety-guard** обходится промпт-инъекцией (наивные подстроки) — важно для детского продукта.
- 🟡 **Fallback-auth TTL 24 ч** без отзыва.
- 🟢 Секреты не утекают в ответы/фронт; SQL параметризован; XSS в чате закрыт (`textContent`); PII-редакция перед записью истории. *(Секреты в этом аудите не читались.)*
