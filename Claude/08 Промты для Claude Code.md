# Промты для Claude Code

> Готовые промты для копирования. Связано с [[00 Индекс проекта]] · [[05 Первые задачи]].

## Анализ без изменений

```text
Прочитай CLAUDE.md и документы в папке Claude. Проанализируй указанную часть проекта. Код не меняй. Дай вывод, риски и план.
```

## План изменения

```text
Прочитай CLAUDE.md. Подготовь план изменения по задаче: [описание задачи]. Код пока не меняй. Укажи файлы, риски и проверки.
```

## Безопасное изменение

```text
Прочитай CLAUDE.md. Выполни только задачу: [описание задачи]. Не делай лишних изменений. После изменения запусти доступные проверки и обнови Claude/06 Журнал изменений.md.
```

## Аудит голосового модуля

```text
Прочитай CLAUDE.md. Проведи аудит голосового модуля как разработчик и как пользователь. Код не меняй. Найди баги, задержки, ошибки API, проблемы UX и составь план исправления.
```

## Аудит генерации картинок

```text
Прочитай CLAUDE.md. Проведи аудит генерации картинок для карточек слов. Код не меняй. Проверь, почему картинки долго создаются, почему создаются не всегда, как работает кеширование и как улучшить подбор изображений для существительных, глаголов, прилагательных и абстрактных слов.
```

## Аудит словаря и тренировок

```text
Прочитай CLAUDE.md. Проведи аудит режима изучения слов и тренировок «Выбрать перевод» / «Написать слово». Код не меняй. Найди баги, проблемы загрузки, сохранения прогресса и UX. Составь план маленьких безопасных улучшений.
```

## Ревью перед коммитом

```text
Прочитай CLAUDE.md. Сделай ревью текущего диффа: корректность, риски, упрощения. Коммит не создавай. Дай список замечаний по приоритету.
```
