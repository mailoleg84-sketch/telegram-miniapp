# 🎨 UX-аудит интерфейса (как пользователь)

> Проверка живого приложения + ревью дизайна 4 агентами. Код **не менялся**. Связано с [[03 Технический аудит]] · [[09 Идеи и улучшения]].

## Как проверяли
- Поднял Mini App локально (`tools.run_webapp_local`, без бота/webhook), **мобильный вьюпорт 375×812**, зашёл по подписанной fallback-ссылке.
- Прошёл вживую: **экран регистрации** и **главный экран** (после регистрации тестового профиля, потом удалил его из БД). Снял реальные вычисленные стили (шрифты, размеры, цвета, тач-зоны), проверил переполнение и консоль.
- 4 агента параллельно отревьюили весь CSS/JS-исходник по измерениям: типографика, цвет/контраст, layout/мобайл, анимации/состояния.
- ⚠️ Скриншоты не снялись (рендерер «зависал») — и это оказалось **симптомом находки**: постоянные бесконечные анимации (см. ниже).

## Общая оценка: **~5.7 / 10**
Фундамент хороший: дизайн-система с токенами, шрифт Nunito, тёмная тема, возрастная адаптация, safe-area, haptics, `:active`, пустые состояния. Но для **детской** аудитории есть несколько системных проблем — контраст, мелкий текст, тач-зоны и «вечные» анимации.

---

## 🔴 Критичное (исправить в первую очередь)

1. **Бесконечные анимации работают всегда** — `tutorPresence` (`styles.css:2946`), `avatarBreath` (`2987`), `avatarBlink` (`3007`) навешаны на элемент, а не на состояние → постоянный GPU-перерендер даже в простое. На телефоне ребёнка = разряд батареи и нагрев. *(Это же «вешало» скриншот.)* Плюс `prefers-reduced-motion` не покрывает `tutorPresence`.
2. **Контраст плашек ответа — провал.** Белый текст на зелёном `#34c759` = **1.97:1**, на красном `#ff3b30` = **3.55:1** (нужно 4.5:1). Ребёнок читает их каждые несколько секунд в тренировках. *(WCAG-расчёт агента.)*
3. **Фокус-индикатор почти невидим** — `outline` с `opacity 0.12–0.22` (`design.css:397`, `styles.css:2115`) ≈ 1.1–1.3:1, нарушает WCAG 2.2 (нужно 3:1). Клавиатура/спец-доступ не работают.
4. **Главная кнопка озвучки `.pronounce-btn` 36–40px** (`styles.css:149/1910`) — меньше 44px. Самая нажимаемая кнопка в изучении слов; малыши промахиваются. Аналогично `.voice-action` 30–34px.
5. **Поле ввода чата перекрывается клавиатурой на iOS** — нет обработки `Telegram.WebApp.onEvent('viewportChanged')`; ребёнок не видит, что печатает.
6. **Верх градиента основной кнопки** `#8b7bff` на белом = **3.13:1** — белый текст не проходит AA.

## 🟠 Важное
- **Текст нижней навигации 11px** (`design.css:341`) — мелко для детей 5–10; это основной навигатор.
- **Вес 900 повсюду** (h1/h2/кнопки/плитки) — нет визуальной иерархии, «всё жирное». Рекомендация: h2/кнопки → 700, h1 оставить 800–900.
- **Текст плиток меню 13.3px** — мелковато для иконочного меню.
- **Анимации `box-shadow`** (`voiceButtonPulse:3633`, `avatarGlowPulse:496`) — дорогая операция; лучше `opacity` псевдоэлемента.
- **`renderError` показывает сырое техническое сообщение** (`app.js:778`) детям («HTTP 503»). Для голоса дружелюбные тексты уже есть (`friendlyVoiceError`) — распространить на общий обработчик.
- **Смысл только цветом** — правильно/неправильно и активный таб различаются лишь цветом (плохо для дальтоников/малышей); добавить иконку/✓/✗/жирность.
- **Цвет подсказок `#6b7394` на белом = 4.19:1** — чуть ниже AA для 14px; затемнить до ~`#5d6482`.

## 🟡 Умеренное
- Все размеры в `px` (не `rem`) → текст не масштабируется при крупном системном шрифте.
- Возрастная типографика не покрывает мелкие тексты (`.hint`, подписи, навигацию) для группы 5–7.
- `line-height: 1.32` на кириллице в мелких подписях — тесно (нужно ≥1.45).
- `overflow-wrap: normal` на плитках → длинные русские слова могут ломать сетку (особенно 320px).
- Словарь без `content-visibility` → тормоза при 100+ словах.
- Горизонтальные `padding: …4px` в строках словаря/лидерборда — тесно у края.
- Мёртвый код: `max-width: 560px` у `#app`, дублирующий `--font-display` (SF Pro Rounded) в `styles.css`.

## 🟢 Что сделано хорошо
Nunito реально подключён (`@import`, `display=swap`); основной текст `#1c2440` на белом = **13:1**; тёмная тема (`prefers-color-scheme` + `data-theme`); базовый `prefers-reduced-motion` reset; `viewport-fit=cover` + `env(safe-area-inset-bottom)`; haptics на кнопках; `:active`-отклик; `disabled` во время запросов; понятные пустые состояния словаря; **горизонтального переполнения нет**, на пройденных экранах тач-зоны кнопок/инпутов = 50px.

---

## 🎯 Топ-7 правок (сводно от агентов)
1. Остановить «вечные» анимации аватара в простое + добавить их в `prefers-reduced-motion` (батарея).
2. Поднять контраст плашек ответа: зелёный → `#1a8c4e`, красный → `#c0001a` (или тёмный текст).
3. Видимый фокус: `outline: 3px solid var(--accent); outline-offset: 2px`.
4. `.pronounce-btn`, `.voice-action`, `.chat-reset` → `min-height/width: 44px`.
5. Нижняя навигация: 11px → 13px (минимум), для 5–7 → 14px.
6. Снизить вес 900 → 700 для h2/кнопок (вернуть иерархию).
7. Клавиатура iOS: слушать `viewportChanged`, сдвигать поле ввода.

> Это **дизайн-долг**, не блокеры — приложение функционально и стабильно (подтверждено live-проверкой). Правки можно вносить пачками по приоритету; почти всё — точечные CSS-изменения с низким риском.
