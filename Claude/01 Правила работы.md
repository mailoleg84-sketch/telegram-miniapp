# Правила работы

> Краткая версия правил из `CLAUDE.md` (корень проекта). Полный свод — там. Связано с [[00 Индекс проекта]].

## Главные принципы

- Работаем **маленькими безопасными шагами**, без хаотичных изменений.
- **Сначала план — потом код.** Никаких правок без подтверждения.
- Стабильность рабочей версии важнее скорости.

## Запреты

- ❌ Не удалять файлы без отдельного подтверждения.
- ❌ Не трогать `.env`, API-ключи, токены, пароли, секреты.
- ❌ Не редактировать `node_modules`, `.git`, `dist`, `build`, `.next`, `.venv`, `__pycache__`, кэши и временные папки.
- ❌ Не создавать коммиты без разрешения.
- ❌ Не менять бизнес-логику, если задача этого прямо не требует.

## Перед любым изменением кода объясни

1. Какую проблему решаешь.
2. Какие файлы будешь менять.
3. Что именно изменишь.
4. Ожидаемый результат.
5. Риски.

Затем напиши: **«План изменений готов. Подтверждаете, что можно внести эти изменения?»** — и жди ответа.

## Рабочий процесс

1. Изучить структуру проекта ([[02 Карта проекта]]).
2. Прочитать документы в `Claude`.
3. Предложить план.
4. Дождаться подтверждения.
5. Внести изменения.
6. Проверить результат (тесты / py_compile / node --check).
7. Записать отчёт в [[06 Журнал изменений]].

## После изменений — проверки

```bash
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\python.exe -m py_compile config.py database.py webapp\server.py webapp\openai_service.py webapp\lesson_engine.py
node --check webapp\static\app.js
```

## Приоритеты

Стабильность → скорость (словарь/озвучка/картинки) → изучение слов → тренировки → голос → картинки → детский UI → безопасность данных → удобство → масштабируемость.
